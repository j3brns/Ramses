# Ramses ident

`explorations/voxel-house-white-v4.png` is the selected production README ident. It combines the cross-section insight of the first voxel-house composition with a denser modular engineering model: roof sundial, passing sun, programme traces, burner, hot-water vessel, valves, radiator and return loop. Its backdrop is pure white, not paper, cream, sepia or an aged finish; the bright cyan, yellow, orange, red and green palette is intentional for Markdown legibility. The dark wireframe sundial remains retained for dark dashboard and panel surfaces.

`sundial-wireframe.png` is the selected README ident. It is an original vector-like raster illustration: a sundial, schedule ticks and a travelling sun are viewed through an abstract wireframe arcade instrument window. The visual language nods to early wireframe arcade simulators without reproducing a game, vehicle, logo, interface, or other protected asset.

## Iteration policy

Treat the prompt and the visual criteria as source. Keep all non-trivial candidate versions, add a numbered prompt revision, review at README-banner scale, and record why an iteration was selected or rejected. For a truly scalable replacement, add a hand-authored SVG with the same composition rather than claiming this PNG is literal vector artwork.

## Expanded house-style exploration

### Production selection: white voxel house v4

`explorations/voxel-house-white-v4.png` replaces the wireframe image in the top-level README. It is the selected light-background production asset, not a temporary exploration. It preserves the house-as-environment and time-through-the-day story from voxel v1, applies the more explicit blockwork from voxel v2, and enforces a pure `#FFFFFF` background with bright, clear colours. It is an explanatory ident, not a Home Assistant screenshot or a description of live target-system state.

The current README ident remains the selected minimal dark overlay. Three additional directions were generated and reviewed after studying the public `j3brns/symphonic` documentation imagery:

- `explorations/symphonic-vessel-v2.png` — recommended future documentation/banner style: practical water-heating machinery, sundial timing and pale engineering-paper HUD framing.
- `explorations/overlay-v2.png` — recommended future dashboard/panel style: flat dark instrumentation overlay with the causal loop from sun/schedule to vessel, valve and radiator.
- `explorations/voxel-matrix-v2.png` — retained as an explanatory learning or digital-twin illustration; it is intentionally more playful and less appropriate as the core brand ident.

The Symphonic influence is limited to broad principles—pale paper, forest-green technical framing, small status diagrams and readable instrumentation—not its names, robots, text or compositions.
