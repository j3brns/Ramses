# Skills and capabilities

Ramses is maintained through capability contracts, not a fixed proprietary agent toolkit. The required capabilities are deterministic Python testing, repository gates, documentation/provenance, test-only MQTT isolation and computer-use UI acceptance.

The authoritative inventory is [Skills inventory and maintenance contract](../skills-inventory.md). Future agents may substitute tools, but cannot omit the required evidence or safety boundary.
