# Adversarial review: ident house-style exploration

## Scope

Three refined visual directions prompted by the public Symphonic README/banner and documentation images: practical engineering vessel, dark action overlay and voxel matrix model.

## Failure modes

- Copying Symphonic's words, robots, layout or named visual assets rather than learning its design principles.
- Treating a game-inspired scene as a heating-programmer UI.
- Reintroducing the unwanted cockpit/parallax treatment in the dark overlay.
- Selecting a visually entertaining illustration that obscures the physical heating loop.

## Evidence and tests

The Symphonic public images were reviewed: they consistently use pale engineering paper, forest-green technical framing, compact status panels and a readable instrumentation hierarchy. Three original candidates were generated, their first versions were compared in File Explorer via computer use, and each was refined for clarity and originality. Prompts and candidates are retained under `assets/ident/`.

## Decision

Keep the existing minimal dark wireframe sundial as the README ident. Adopt the practical vessel as the prospective documentation house style, the dark action overlay as the prospective dashboard/panel style, and the voxel matrix as an optional explanatory digital-twin image.

## Rollback

Remove `assets/ident/explorations/` and this note; no operational or Home Assistant behaviour is affected.
